# Tailspin Shelter UX

These are paired draft contracts for the Tailspin Shelter Next.js frontend epic:

- [`DESIGN.md`](DESIGN.md) defines the visual identity and component appearance.
- [`EXPERIENCE.md`](EXPERIENCE.md) defines information architecture, behavior, copy, states, accessibility, and journeys.

The epic ticket is the requirements source. The existing Astro pages and components under `app/client/src/` are the fidelity reference for the current site.

## Confirmed direction

- Faithfully preserve the existing layout, color palette, typography, and responsive behavior; no redesign.
- Support responsive desktop and mobile browsers.
- Keep controls semantic and keyboard-operable; make no formal WCAG conformance claim.
- Center the key journey on Riley, a representative prospective adopter browsing dogs on a phone.

Both spines are final. No unresolved UX decisions remain from the ticket, approved memlog decisions, and inspected Astro reference.
